# 萬用計算機（手機版）部署說明

把「開發專用計算機V1.0.exe」（視窗標題：萬用計算機）的 9 個計算功能做成網頁版。放到免費空間後，用 iPhone 開啟、「加入主畫面」，就能像 App 一樣使用，**開啟過一次之後沒有網路也能用**。

## 一、這個資料夾裡有什麼

| 檔案 | 用途 |
|---|---|
| `index.html`、`style.css`、`app.js`、`calc.js` | 網頁本體（`calc.js` 是全部的計算公式） |
| `sw.js` | 離線快取（讓沒有網路時也能開啟） |
| `manifest.webmanifest`、`icons/` | 主畫面圖示與 App 設定 |
| `_headers`、`.nojekyll` | 部署平台用的設定，不用動 |
| `README.md` | 本說明（上傳後也會公開，無妨） |

**上傳時，這個資料夾裡的所有檔案要一起上傳**（包含開頭是 `.` 或 `_` 的檔案，以及 `icons` 資料夾）。網站的最上層必須直接看得到 `index.html`。

## 二、上傳到免費空間（三選一）

> 必須是 **https** 網址（下面三個平台都是）。直接在 Google 雲端硬碟裡開 `index.html`，或用雲端硬碟的分享連結，是**無法**當網頁使用的。

### 方法 A：Netlify（最簡單，用拖拉的）
1. 開啟 <https://app.netlify.com/drop>，用 Google 帳號登入（免費）。
2. 把整個「測試」資料夾拖進頁面。
3. 完成後會得到 `https://xxxx.netlify.app`，用手機開這個網址。
4. 之後要更新：到該站台的 Deploys 頁面，再拖一次資料夾。

### 方法 B：Cloudflare Pages（免費、流量不限）
1. 登入 <https://dash.cloudflare.com> → Workers & Pages → Create → Pages → **Upload assets**。
2. 取個專案名稱 → 上傳「測試」資料夾 → Deploy。
3. 網址是 `https://專案名稱.pages.dev`。

### 方法 C：GitHub Pages
1. 建立 GitHub 帳號與一個公開的儲存庫（例如 `calc`）。
2. 把「測試」資料夾內的所有檔案上傳到儲存庫（網頁上 Add file → Upload files）。
3. Settings → Pages → Branch 選 `main`、資料夾選 `/ (root)` → Save。
4. 約 1～2 分鐘後，網址是 `https://你的帳號.github.io/calc/`。

網站放在網址的最上層或子路徑（例如上面的 `/calc/`），都能正常運作。

## 三、在 iPhone 加入主畫面

1. 用 **Safari** 開啟你的網址（第一次需要連網）。
2. 點下方的「分享」按鈕（方框加向上箭頭）→ 往下找「**加入主畫面**」→「加入」。
3. 主畫面會出現「萬用計算機」圖示。從圖示開啟，就是全螢幕的 App 介面。
4. 開啟過一次之後，檔案已存在手機裡，**飛航模式也能使用**。

建議一定要「加入主畫面」：直接用 Safari 瀏覽的網站，若超過一週沒開，iOS 可能會清掉它存的資料；加入主畫面的 App 不受這個限制。

（iOS 16.4 以上，用 iPhone 的 Chrome／Edge 開啟，也可以從分享選單「加入主畫面」。）

## 四、日後要更新網頁怎麼辦

- 修改檔案後，用原來的方式**再上傳一次**。
- 手機下次開啟（有網路時）會在背景自動下載新版，**再開一次 App 就是新版**。
- 如果做了大改版，建議把 `sw.js` 開頭的 `VERSION = 'v1.0.0'` 改成新的字串（例如 `'v1.1.0'`），手機會整組重新安裝。
- 萬一手機一直停在舊版：刪除主畫面圖示後重新加入；或到 設定 → App → Safari → 進階 → 網站資料，刪除該網址的資料。

## 五、使用小提醒

- 欄位下方灰色的說明文字很多，右上角的 ⓘ 可以一鍵隱藏／顯示。
- 輸入的數字**只會存在你的手機**，下次開啟還在；每張卡片右上角的「清除」可還原預設值。
- iPhone 的數字鍵盤沒有「完成」鍵：點一下空白處，或按「計算」，鍵盤就會收起。
- 這是公開網站：知道網址的人都能開，但裡面只有公式與工程參考值，沒有任何個人資料。

## 六、跟原本 exe 的差異

計算公式、單位換算、預設值、提示文字，全部沿用原程式。已經用約 25,000 組隨機測資，與**原程式實際執行的結果**逐筆比對（包含錯誤提示訊息與四捨五入的方式），結果完全一致。

為了手機操作，做了這些調整：

- 輸入時**即時顯示結果**（仍保留「計算」按鈕；按下去若有欄位沒填好，會顯示和原程式相同的提示）。結果捲出畫面時，上方會浮出一條迷你結果列。
- 參考表（馬達扭力、傳動效率、氣缸缸徑／桿徑、轉子慣量）改成點欄位旁的「參考表」彈出，點一下數值就會帶入。
- 螺桿挫曲強度檢核收在「馬達扭力計算機」最下方的折疊區。
- 輸入框也接受全形數字（中文輸入法常見）。
- 結果旁有「複製」鈕。
- 原程式文字中的「谷径」是簡體字寫法，網頁版改為「谷徑」。
